# FixMyBill — React Application

Smart Bill Vault & Financial Tracking Web Application built with React, Vite, TypeScript, and modern modular component architecture.

## Features Ported & Converted to React:
- **Interactive Top Navbar**: Sticky glassmorphism header with desktop and responsive mobile drawer navigation, brand identity, and action handlers.
- **Hero & Expense Scanner Module**:
  - Greeting banner & value proposition
  - 3-Way Instant Actions: Smart Camera Scanner, File/Receipt Drag-and-Drop Uploader, and Manual Expense Entry modal forms
  - Trust strip with security compliance badges
- **This Month Overview**: Interactive real-time summary cards with dynamic spend calculations, saved bills count, and review queue with month filter selection.
- **Recent Activity Feed**:
  - Filterable by transaction status (`All`, `Matched`, `Needs Bill`, `Verified`)
  - Real-time search query filter across payees and expense categories
  - Expandable modal view to inspect proof of payment and attach missing receipts
  - Add new transaction capability with live state updates
- **Product Features & Call-to-Action**: High-converting showcase and footer links.
- **Toast Alert System**: Contextual toast notifications for user interactions and simulations.

## Tech Stack:
- React 19
- TypeScript
- Vite
- Lucide React
